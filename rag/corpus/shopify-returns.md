# Shopify Store — Return Policy of this Seller (simulated)

## Return window
The seller's own store accepts returns within 30 days after delivery. Shopify does not track
delivery itself; the date comes from the carrier tracking update.

## Exchanges
Buyers can exchange for another size or colour once for free. An exchange creates a return of the
old line and a new order line; there is no money refund.

## Store credit
Buyers can choose store credit instead of money. Store credit is issued immediately and the
return is still counted.

## Final sale
Items marked "final sale" (clearance, personalised products) cannot be returned unless defective.

## Guidance
Exchanges are a strong signal of size problems. If one SKU has many exchanges, update the size
guide before buying more stock.

# Amazon — Return and Refund Policy (simulated)

## Return window
Buyers can request a return within 30 days after delivery. Amazon only gives the seller an
estimated delivery date, so the seller counts the window from the estimated date.

## Who approves
Most return requests are approved automatically by the marketplace. The seller sees the approved
request, not the buyer's conversation. A refund can be issued before the item arrives back
("returnless refund") for low-price items under 15 USD.

## Return reasons
Common reasons: wrong size, item defective, not as described, no longer needed, arrived late.
Size and fit problems are the largest group for apparel SKUs.

## Restocking
Opened electronics may get a restocking fee of up to 20% when the reason is "no longer needed".
No fee applies when the item is defective or not as described.

## What the seller should do
- Watch SKUs whose 90-day return-or-refund rate is above 15%: check the size chart and photos.
- Inspect returned items within 3 days; failed inspection still counts as a return for the label.

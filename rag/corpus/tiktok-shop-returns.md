# TikTok Shop — Return and Refund Policy (simulated)

## Return window
15 days after delivery for most categories, 30 days for electronics. TikTok Shop shows a delivered
status to the seller.

## Seller response time
The seller must accept or reject a return request within 48 hours. If the seller does not answer,
the request is approved automatically.

## Refund only
Buyers can ask for "refund only" without sending the item back when the item is missing, damaged in
transit, or much cheaper than the return shipping cost.

## Live-stream orders
Orders bought during a live stream have a higher return rate because buyers decide fast. Sellers
should describe size and material clearly during the stream.

## Guidance
Reject a request only with photo evidence. Rejected requests that the platform later overturns
still count as a return.
